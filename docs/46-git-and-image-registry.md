# 46 — سرویس Git و مخزن ایمیج Docker

هر دو مثل بقیه سرویس‌ها از «سرویس‌های من ← افزودن سرویس» نصب می‌شوند ([سند 44](44-split-services-and-install-wizard.md))
و پنل آن‌ها را از صفحه «کد و ایمیج‌ها» مدیریت می‌کند.

## Git (Gitea)

**چرا Gitea و نه GitLab:** GitLab برای کار عادی ۴ تا ۸ گیگابایت رم می‌خواهد و چند سرویس جدا دارد؛ Gitea یک
برنامه است، با حدود ۲۵۰ تا ۵۰۰ مگابایت کار می‌کند و API کامل دارد. پنل آن را کامل از راه همین API مدیریت می‌کند.

| | |
|---|---|
| image | `gitea/gitea:1.24.7-rootless` (با digest ثابت) |
| دیتابیس | SQLite خود Gitea در volume ‏`mrk-git-data`؛ به هیچ سرویس دیگری وابسته نیست |
| شروع | `mrk-git-init` (یک‌بار) پایگاه داده را آماده و کاربر مدیر `mrk-panel` را با رمز `.env` می‌سازد |
| اتصال پنل | پنل یک بار با این رمز کلید API می‌سازد و فقط کلید را در SecretStore نگه می‌دارد |
| پورت‌ها | وب 3000 و SSH ‏2222، پیش‌فرض فقط روی `127.0.0.1` |

پنل: فهرست و ساخت مخزن، **آینه مخزن‌های GitHub/GitLab** (با فاصله همگام‌سازی، برای وقتی که GitHub کند یا
بسته است)، همگام‌سازی فوری، حذف با تأیید تایپی، کاربران (رمز یک‌بار نمایش و تغییر اجباری در اولین ورود) و
سازمان‌ها. ثبت‌نام آزاد بسته است و مخزن‌ها پیش‌فرض خصوصی‌اند. منبع آینه فقط `https://` عمومی است (نشانی
داخلی، loopback یا با رمز در URL رد می‌شود).

## مخزن ایمیج Docker (Zot)

**چرا Zot:** هم‌زمان مخزن خصوصی (push/pull) و آینه on-demand چند رجیستری است و برای هر کدام فهرست
نشانی‌های پشتیبان دارد که به‌ترتیب امتحان می‌شوند؛ تنظیمات و کاربرانش را بدون ری‌استارت دوباره می‌خواند.

| | |
|---|---|
| image | `ghcr.io/project-zot/zot:v2.1.23` (با digest ثابت) |
| داده | volume ‏`mrk-registry-data` |
| تنظیمات | پنل `config.json` و `htpasswd` (bcrypt) را در volume مشترک `mrk-registry-config` می‌نویسد؛ Zot خودش reload می‌کند |
| آینه‌ها | ghcr.io → `/ghcr.io`، quay.io → `/quay.io`، registry.k8s.io → `/registry.k8s.io`، Docker Hub → ریشه |
| دسترسی Docker از راه پنل | اختیاری: Zot برای مجوز Docker را به پنل می‌فرستد؛ از رنج IP مورد اعتماد (خود سرور، سرورهای ساخت) دریافت بدون رمز، بقیه با رمز. برای `registry-mirrors` در `daemon.json` لازم است چون Docker برای آینه رمز نمی‌فرستد ([سند 48](48-build-mirrors.md)) |
| کاربران | `mrk-panel` (مدیر، برای پنل)، و کاربران pull یا push که پنل می‌سازد؛ رمز یک بار نشان داده می‌شود |
| پورت | 5000، پیش‌فرض فقط روی `127.0.0.1`؛ Docker فقط با HTTPS وصل می‌شود، پس دامنه بدهید |

Docker Hub پیش‌فرض با `registry-1.docker.io` و `mirror.gcr.io` (پشتیبان) تنظیم شده؛ آینه‌های داخلی (مثلاً
`https://docker.arvancloud.ir`) را می‌توان از پنل جلوی فهرست گذاشت.

## دسترسی‌ها

`git:read` / `git:write` و `registry:read` / `registry:write` (مالک و admin همه، operator همه، developer فقط
خواندن). هر تغییر در تاریخچه کارها ثبت می‌شود.
