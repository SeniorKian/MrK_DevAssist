# Code of Conduct

Pishkar adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. The full text applies to every project space: issues, pull requests,
discussions, chats and events where you represent the project. Translations, including Persian,
are listed at <https://www.contributor-covenant.org/translations/>.

In short: be respectful and welcoming, accept constructive criticism, focus on what is best for
the community, and do not harass, insult or publish others' private information.
